# Модуль: Карточки слов (`docs/modules/flashcards/`)

## 1. Назначение и концепция
Модуль «Карточки» предназначен для визуального и слухового закрепления словарного запаса. Работает по принципу интервального повторения и самопроверки.

## 2. Ключевые компоненты
- `app/src/main/java/com/example/ui/screens/FlashcardsScreen.kt`:
  - Интерактивный стек карточек со словами из базы данных (`dictionary_words`).
  - Лицевая сторона: крупное слово со знаком ударения, часть речи, кнопка мгновенного аудио-произношения.
  - Оборотная сторона: толкование на русском языке, контекстное предложение с выделенным словом, категория.
  - Кнопки самооценки:
    - «Повторить позже» (оставляет слово в активном цикле повторений).
    - «Знаю это слово!» (помечает слово как освоенное, начисляет +15 XP и инкрементирует `wordsLearnedCount`).
  - Переключение режимов: показ всех слов, только избранных или только неосвоенных.

## 3. Бизнес-логика
- Данные берутся напрямую из `MainViewModel.allWords` (поток из Room DB).
- При нажатии «Знаю это слово!» вызывается `viewModel.markWordMastered(word, true)`:
  - В БД `dictionary_words` поле `isMastered` становится `true`.
  - Поле `repetitionCount` инкрементируется на 1.
  - В `user_progress` через репозиторий начисляются очки опыта и обновляется счетчик изученных слов.
- Кнопка «Звук» на карточке инициирует `viewModel.speakText(word.word)`.
