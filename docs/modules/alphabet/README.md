# Модуль: Алфавит (`docs/modules/alphabet/`)

## 1. Назначение и концепция
Модуль «Алфавит» обеспечивает базовый этап обучения («Фундамент») в методологии приложения «Любопытная Катя».
Пока ученик не познакомится со всеми 33 буквами русского алфавита (или не подтвердит владение через экстренный зачёт), продвинутые разделы приложения (Тренажёр «Попугай», Карточки, Словарь) блокируются защитным экраном `LockedSectionView`.

## 2. Ключевые компоненты
- `app/src/main/java/com/example/ui/screens/AlphabetScreen.kt`:
  - Интерактивная сетка русских букв с группировкой по категориям (Гласные, Звонкие согласные, Глухие согласные, Знаки).
  - Режим **Спринт-тап (Tap-only mode)**: мгновенное озвучивание букв при быстром касании для слуховой автоматизации.
  - Детальная карточка буквы: транскрипция/звучание, описание артикуляции, наглядные примеры слов с эмодзи и контекстом.
- `app/src/main/java/com/example/data/AlphabetData.kt`:
  - Полный реестр 33 букв русского алфавита (`List<LetterItem>`).
  - Классификация по `LetterType`: `VOWEL`, `CONSONANT_VOICED`, `CONSONANT_VOICELESS`, `SIGN`.
  - Модель данных `LetterItem(letter, lowerLetter, sound, type, description, examples)`.

## 3. Бизнес-логика и сценарии
- **Прогресс изучения**: При клике на букву вызывается `viewModel.onLetterTapped(letter)`, который озвучивает букву через `TtsManager` и передает событие в `RussianLearningRepository.recordLetterPracticed(letter, userProgress)`.
- Буква добавляется в множество `learnedLettersSet` в таблице `user_progress`.
- При достижении 33 уникальных букв:
  - Автоматически выставляется флаг `isAlphabetMastered = true`.
  - Открывается бейдж «Знаток азбуки» (`badge_alphabet`).
  - Начисляется бонус +50 XP.
  - Снимается блокировка с разделов тренажёра, карточек и словаря.
- **Шлюз быстрого зачёта**: Если пользователь уже владеет алфавитом, он может нажать кнопку «Я уже знаю алфавит» в `LockedSectionView`, что вызывает `viewModel.unlockAlphabetByPass()`.
